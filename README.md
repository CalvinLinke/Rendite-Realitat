# Rendite & Realität

Astro-Website für das persönliche Immobilien- und Unternehmerjournal **Rendite & Realität**.

## Start

```bash
npm install
npm run dev
```

## Vercel

- Framework Preset: `Astro`
- Build Command: `npm run build`
- Output Directory: `dist`

## Vor dem Launch anpassen

- echte Kontakt-E-Mail in `src/pages/kontakt.astro`
- Impressum und Datenschutz ergänzen
- finale Domain in `astro.config.mjs`
- bei Bedarf Bilder und weitere Markdown-Beiträge aus dem lokalen Projekt ergänzen
